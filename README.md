# orbita-versoes

Repositório público de versões do **Órbita**, organizador de vida gratuito para pessoas neurodivergentes. Aqui ficam os instaladores e as notas de cada versão.

## Páginas públicas

Publicadas pelo GitHub Pages em https://danielsampaiorodrigues.github.io/orbita-versoes/

- `index.html`: apresentação do Órbita (página inicial).
- `privacidade.html`: política de privacidade, incluindo o uso opcional da conta Google ou Microsoft.

O arquivo `.nojekyll` faz o GitHub Pages servir os arquivos como estão.
